## 👋 Introduction

> Because the original open-source BewlyBewly used the ["tabs" permission](https://developer.chrome.com/docs/extensions/reference/api/tabs),This permission can also be used to read each tab to understand browsing history, but it is not used here.
>
> **Some browsers may mention the worst-case scenario and highest risk to ensure your safety after installation.**
> In addition, this project is open source, so you can also see what it is doing as it is open source 6(^o^)9

BlightBlight is based on[BewlyBewly](https://github.com/BewlyBewly/BewlyBewly)Assist in utilizing AI for better use of Bilibili plugins. The design inspiration comes from YouTube, Vision OS, and iOS, resulting in a more visually appealing and user-friendly interface.

This project uses [vitesse-webext](https://github.com/antfu/vitesse-webext) Develop templates. Without this template, it may not be possible to develop this project.


## ⬇️ Install

#### 1.Edge

> Make sure you have downloaded it [BlightBlight
 x.x.zip](https://github.com/smalldog54188/BlightBlight/releases) And unzip the file.

1.Enter in the address bar` edge://extensions/ `And press Enter
2. Open 'Developer Mode' and click 'Load Unextracted Extension' <br/> <img width="655" alt="image" src="https://user-images.githubusercontent.com/33394391/232246901-e3544c16-bde2-480d-b770-ca5242793963.png">
