## 👋 介绍

> 因为原先开源BewlyBewly使用嘞。["tabs" 权限](https://developer.chrome.com/docs/extensions/reference/api/tabs)，应该权限都可用于读取个个标签页，从而了解擸一眼历史，但喺呢度并未使用。
>
> **啲浏览器会提到最衰嘅环境同埋最高嘅风险，以确保你喺安装后嘅安全。**
> 外加，呢個項目係開放源碼，所以會同樣開放源碼你都睇到做乜 6(^o^)9

BlightBlight 系基于[BewlyBewly](https://github.com/BewlyBewly/BewlyBewly)辅助利用AI，嚟更加好用嘅B企插件。设计灵感嚟自于YouTube、Vision OS同iOS，从而实现咗更副视觉吸引力同用户友好性嘅介面。

应该项目使用 [vitesse-webext](https://github.com/antfu/vitesse-webext) 模板进行开发。如果冇呢个模板，可能唔开发出呢个项目。

#### Edge

> 确保你下载嘞 [BlightBlight
