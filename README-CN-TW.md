## 👋 介紹

> 因為原開源 BewlyBewly 使用了["tabs" 权限](https://developer.chrome.com/docs/extensions/reference/api/tabs)，該許可權也可用於讀取每個標籤頁，從而瞭解瀏覽歷史，但在這裡並未使用。
>
> **一些瀏覽器會提到最壞的情况和最高的風險，以確保您在安裝後的安全。**
> 此外，這個項目是開源的，所以會同樣開源你也能查看到在幹什麼 6(^o^)9

BlightBlight 是基於[BewlyBewly](https://github.com/BewlyBewly/BewlyBewly)輔助利用AI，以便更好用的B站挿件。 設計靈感來自於 YouTube、Vision OS 和 iOS，從而實現了更具視覺吸引力和用戶友好性的介面。

該項目使用 [vitesse-webext](https://github.com/antfu/vitesse-webext) 範本進行開發。 如果沒有這個範本，可能無法開發出這個項目。

### 2.github直接下載

#### Edge

> 確保您下載了 [BlightBlight
 x.x.zip](https://github.com/smalldog54188/BlightBlight/releases) 並解壓縮該檔案。

1.在地址欄輸入 `edge://extensions/` 並按回車
2. 打開`開發者模式`並點擊`加載已解壓的拓展程式` <br/> <img width="655" alt="image" src="https://user-images.githubusercontent.com/33394391/232246901-e3544c16-bde2-480d-b770-ca5242793963.png">
3. 在瀏覽器中加載解壓後的擴展資料夾

#### Chrome
