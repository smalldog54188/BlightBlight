## 👋 介绍

> 因为原开源 BewlyBewly 使用了["tabs" 权限](https://developer.chrome.com/docs/extensions/reference/api/tabs)，该权限也可用于读取每个标签页，从而了解浏览历史，但在这里并未使用。
>
> **一些浏览器会提到最坏的情况和最高的风险，以确保您在安装后的安全。**
> 此外，这个项目是开源的，所以会同样开源你也能查看到在干什么 6(^o^)9

BlightBlight 是基于[BewlyBewly](https://github.com/BewlyBewly/BewlyBewly)辅助利用AI，以便更好用的B站插件。设计灵感来自于 YouTube、Vision OS 和 iOS，从而实现了更具视觉吸引力和用户友好性的界面。

该项目使用 [vitesse-webext](https://github.com/antfu/vitesse-webext) 模板进行开发。如果没有这个模板，可能无法开发出这个项目。

## ⬇️ 安装

### 1.网盘快速安装
>因部分可能无法使用github，可以使用网盘进行下载zip

>123云盘（推荐）：
>https://1819303252.share.123pan.cn/123pan/tzR9jv-tcdGH
>后续增加更多网盘

### 2.github直接下载

#### Edge

> 确保您下载了 [BlightBlight
 x.x.zip](https://github.com/smalldog54188/BlightBlight/releases) 并解压缩该文件。

1. 在地址栏输入 `edge://extensions/` 并按回车
2. 打开 `开发者模式` 并点击 `加载已解压的拓展程序` <br/> <img width="655" alt="image" src="https://user-images.githubusercontent.com/33394391/232246901-e3544c16-bde2-480d-b770-ca5242793963.png">
3. 在浏览器中加载解压后的扩展文件夹

#### Chrome

> 确保您下载了 [BlightBlight
 x.x.zip](https://github.com/smalldog54188/BlightBlight/releases)  并解压缩该文件。

1. 在地址栏输入 `chrome://extensions/` 并按回车
2. 打开 `开发者模式` 并点击 `加载已解压的拓展程序` <br/> <img width="655" alt="Snipaste_2022-03-27_18-17-04" src="https://user-images.githubusercontent.com/33394391/160276882-13da0484-92c1-47dd-add8-7655c5c2bf1c.png">
3. 在浏览器中加载解压后的扩展文件夹
